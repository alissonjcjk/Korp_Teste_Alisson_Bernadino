# Imagens da aplicação

Esta pasta está reservada às capturas de tela exibidas no `README.md` da raiz.

Use preferencialmente imagens PNG, com a janela da aplicação no mesmo tamanho e
sem dados pessoais, chaves, tokens, terminal ou informações sensíveis visíveis.

## Nomes preparados

| Arquivo | Conteúdo sugerido |
| --- | --- |
| `produtos.png` | Listagem de produtos com pesquisa e ações |
| `cadastro-produto.png` | Modal de criação ou edição de produto |
| `notas-fiscais.png` | Listagem de notas fiscais |
| `analise-ia.png` | Resultado da análise consultiva por IA |

Depois de adicionar uma imagem, substitua o bloco de espaço reservado no
`README.md` pela linha Markdown já deixada dentro do comentário correspondente.

Exemplo:

```markdown
![Tela de produtos do Korp ERP](docs/images/produtos.png)
```
